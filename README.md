difff-kai《ﾃﾞｭﾌﾌ改》
======================

ウェブベースのテキスト比較ツールです。本家サイトが落ちていたため、Japascript版に移植してこちらで公開しています。 

本家サイト： https://difff.jp/

 1. セキュリティ的な安全性の検証:
      •  index.html  および  en/index.html  に記述した JavaScript コードを技術的・セキュリティ的観点から監査します。
      • ネットワーク送信の有無:
          •  onsubmit="compareAndRender(); return false;"
          を用いて、フォームのPOST送信イベントをブラウザ側で完全にブロックしています。
          • コード内に  fetch() 、 XMLHttpRequest() 、 WebSocket 、あるいは外部の追跡タグ（Google
          Analytics等）などの外部通信処理は一切存在しません。
          • 外部のスクリプトやスタイルシート（CDN等）も一切読み込んでいないため、サプライチェーンを介したデータの盗聴リスクもあり
ません。
      • データ保持（永続化）の有無:
          • ブラウザのストレージ（ localStorage 、 sessionStorage 、 Cookie 、 IndexedDB
          等）にテキストを保存するロジックは一切記述していません。
          • タブを閉じる、あるいはリロード（更新）した時点で、入力データはメモリ上から完全に消去されます。

  2. 本家（CGI版）とのセキュリティ比較:
      • 本家CGI版では、たとえローカルに設置したとしても、データを一度サーバーサイドへ送信し、サーバー上のファイルシステム（名
前付きパイプ：FIFO）を経由して diff コマンドを実行するプロセスが発生します。
      • 今回作成した JavaScript 版（デュフフ改）は、「すべての処理が100%ユーザーのブラウザの中だけで完結」します。


ため、サーバーとの通信そのものが一切発生しません。極端に言えば、インターネットをオフライン（機内モード）に切断した状態
でも完璧に動作します。
